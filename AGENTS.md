# Repository Guardrails

- This repository contains data-only icon packages and build-time validation tools. Do not add runtime executable code to a package.
- Keep the production catalog empty until upstream sources, rights, attribution, provenance, and approved distribution are verified.
- Third-party libraries retain their own licenses. Nothing here grants rights in third-party assets.
- Do not publish, tag, release, deploy, or configure repository settings without explicit owner authorization.
- GitHub Releases and pinned download URLs are provisional only; do not represent them as approved or live distribution.
- Preserve source, license, and policy review gates. Synthetic fixtures are test-only and are not production assets.
